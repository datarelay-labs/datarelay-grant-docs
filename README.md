# DataRelay Grant Documentation

Mintlify source for the public **DataRelay Grant** product site and documentation.

DataRelay Grant is an upcoming approval-driven automation and execution-control product from DataRelay Labs. Its initial product definition is based on the approval-management invention represented by **US 12,056,667 B1** and **KR 10-2567118 B1**.

- Product source: https://github.com/datarelay-labs/datarelay-grant
- Patent foundation: US 12,056,667 B1 / KR 10-2567118 B1
- Current status: Coming Soon / pre-release product definition

This repository intentionally documents the patent-backed product foundation without implying that unreleased capabilities are already implemented.
